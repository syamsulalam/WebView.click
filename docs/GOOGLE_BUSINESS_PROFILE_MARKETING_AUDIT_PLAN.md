# Google Business Profile Marketing Audit Plan

Status: implementation tracker, Phase 1-6 implemented, Phase 7 future-only

Goal: add a deterministic `/audit/:businessId` marketing audit that turns the Google Business Profile data we already collect into a client-facing report. The report should show how a business profile compares against local competitors, explain the practical business risk, and point naturally to WebView.click website setup plus Google Business Profile management/optimization services.

## Product Outcome

The audit should work as a sales asset, not a generic SEO report:

- A prospect opens `/audit/:businessId` and sees a focused diagnosis of their Google Business Profile.
- The audit explains what customers can and cannot learn before calling.
- The audit compares the business against nearby competitors in the same city/service category.
- The audit gives simple next actions: launch a website, strengthen review generation, improve profile photos, keep hours/contact data accurate, and optionally let WebView.click manage the profile.
- Admin can download the audit as PDF and attach it to outreach.
- Admin can link the audit next to the generated website preview, e.g. `https://webview.click/audit/{businessId}` and `https://webview.click/{businessId}`.

## Deterministic First

First implementation should not use AI.

Reasons:
- The audit inputs are structured enough: website URL, rating, review count, photos, hours, phone, address, category, Maps URL, competitor rows.
- Deterministic scoring is cheaper, instant, stable, and easier to explain.
- We should avoid unsupported claims. Each recommendation should cite the exact field or comparison that triggered it.

Optional future AI can be added only after the deterministic audit exists:
- Rewrite the deterministic findings into a warmer owner-facing narrative.
- Generate a short outreach email from the audit.
- Summarize review themes from available review text.
- Never let AI invent unavailable profile data, competitor facts, photo recency, or owner review replies.

## Data We Already Have

From current `places_prospects`, `json_sites`, and generated site JSON:

- Business name.
- Business ID generated by WebView.click.
- Google Place ID when the prospect came from Places API.
- Google Maps URL when available.
- Website URL or no-website status.
- Phone number.
- Address.
- Rating.
- Review count.
- Up to 5 review objects from legacy Place Details when details were loaded.
- Photo references and photo attribution metadata.
- Opening hours.
- Types/category/niche.
- Business status.
- Original search query / prospect query in many cases.
- Generated website preview URL.
- Existing feedback page in generated sites that routes 4-5 star visitors toward the Google review URL and lower ratings toward private feedback.

## Data We Need To Be Careful About

Some useful audit ideas are not reliably available from the current Places fields:

- Website URL quality: a profile can contain a URL but still fail the "real website" job if it points to Facebook, Instagram, TikTok, Linktree, a marketplace/directory page, a booking-only URL, or another destination that does not clearly explain services, proof, location, hours, and contact flow. Treat this as `social_or_third_party_profile`, not a full website pass.
- Owner replies to reviews: Google Places API review data does not reliably expose owner reply coverage for arbitrary third-party profiles. This should be marked `unknown` unless we add a manual capture flow or a managed Google Business Profile API integration for locations the owner controls.
- Photo posting frequency/recency: current photo references do not provide reliable posting cadence. We can audit visible photo count and likely variety, but not claim "you have not posted recently" unless future data supports it.
- Profile services/products/posts/questions: these are not in the current legacy Place Details fetch. Treat as future Google Business Profile API/manual-capture opportunities.
- Ranking position: we can compare the target against competitors in the same cached query, but we should avoid claiming real ranking unless the exact search result order and query are known.
- Conversion from profile views: Google Business Profile performance metrics require owner/manager access. Not available for third-party audits.

## Audit Inputs

### Target Business

Resolve by `businessId`:

1. Load generated site from `GET /api/sites/:businessId`.
2. Read `site.sourceData`, `site.businessProfile`, `site.trust`, `site.location`, `site.hours`, `site.brand`, and `site.meta`.
3. Join back to `places_prospects` where `generated_business_id = businessId` to recover `query`, `place_id`, `details_json`, `result_json`, selected photo/palette metadata, and prospect status.
4. Fall back to `leads` by `business_id` for rating/review/website/phone/address if a prospect row is missing.

### Competitors

Resolve competitors deterministically:

1. Prefer the original prospect query from `places_prospects.query`.
2. If query is missing, build a query from category/niche plus city, for example `{primary service} {city} {state}`.
3. Use cached `places_search_cache` rows for that query when available.
4. If not cached and admin explicitly asks to refresh, use Places search with daily usage guardrails.
5. Exclude the target by matching place ID, business name + address, or Maps URL.
6. Keep top 10-20 competitor rows.
7. Normalize competitor fields into `name`, `websiteUrl`, `rating`, `reviewCount`, `photoCount`, `phone`, `address`, `mapsUrl`, and `types`.

Competitor comparison should show confidence:

- `high`: exact cached query and target appears in or near that result set.
- `medium`: same city/category derived from stored profile data.
- `low`: query was inferred and competitor list is sparse.

## Audit Categories To Score

Total score target: 100 points. Use transparent category weights and per-item evidence. V1 scored categories sum to 100; review response is tracked as an advisory signal until reliable reply data exists.

### 1. Website and Customer Research Path - 20 points

What to audit:

- Has website URL on profile.
- Website URL is missing.
- Website URL destination type:
  - `owned_website`: likely a real business website on an owned/domain-style URL.
  - `social_profile`: Facebook, Instagram, TikTok, YouTube, X/Twitter, LinkedIn, Pinterest, or similar.
  - `link_hub`: Linktree, Beacons, Carrd/link page, or similar.
  - `directory_or_marketplace`: Yelp, TripAdvisor, Thumbtack, Angi, DoorDash, booking marketplace, franchise locator, or similar.
  - `booking_only`: scheduler/reservation URL with little business education.
  - `unknown_or_unreachable`: URL exists but cannot be confidently classified.
- Website URL exists but generated site indicates a richer preview is available.
- Phone exists but website missing.
- Maps URL exists.
- Generated WebView preview exists.
- Website CTA path: does the generated site have call/contact/feedback pages.

Owner-facing message:

- If no website: customers who find the Google profile can call, but they cannot learn services, process, pricing cues, project examples, FAQs, or trust details before calling. Competitors with websites can answer those questions before the first call.
- If only social/profile URL exists: the business technically has a link, but it is not the same as a purpose-built website. Social feeds are designed for scrolling and platform engagement, not for a clear service menu, trust proof, FAQs, quote flow, and ownership of the customer journey.
- If website exists: audit can position WebView.click as upgrade/redesign or local landing page expansion.

Recommendations:

- Launch the generated website on a real domain.
- Replace social/directory-only profile links with an owned website URL when possible, while keeping social channels as supporting links on the website.
- Add service/product detail pages.
- Add FAQ and process sections.
- Add click-to-call and request quote flow.
- Keep the feedback/review routing page.

### 2. Review Strength and Social Proof - 25 points

What to audit:

- Rating value.
- Review count.
- Difference from competitor average rating.
- Difference from competitor median/top review count.
- Whether the business is below top competitor review count by a meaningful gap.
- Whether rating is under practical trust thresholds:
  - `< 4.0`: urgent reputation issue.
  - `4.0-4.3`: weak for competitive local service.
  - `4.4-4.6`: acceptable but still vulnerable if competitors are higher.
  - `4.7+`: strong, especially with enough review count.
- Whether review count is too low for the category/city result set.
- Whether available review text exists for proof themes.

Owner-facing message:

- If star rating or review count is lower than competitors, people may call competitors first because reviews are an easy trust shortcut.
- Review count matters as much as rating. A 4.9 rating from 8 reviews may look less trustworthy than a 4.7 rating from 300 reviews.

Recommendations:

- Add a simple review request workflow after every completed job/order.
- Use the generated feedback page: happy customers go to Google review, lower ratings send private feedback first.
- Send review links by SMS/email after delivery.
- Train staff to ask at the right moment.
- Track review count monthly.

### 3. Review Response and Reputation Operations - tracked, not scored in v1

What to audit now:

- Current status is usually `unknown` because Places data does not expose reliable owner reply coverage for arbitrary profiles.
- If future manual capture includes reply snippets, score response coverage and rebalance the weighted score.

Future data:

- Managed GBP API for owner-authorized locations.
- Manual Maps capture that records whether visible reviews have owner responses.

Owner-facing message:

- Responding to reviews shows the business is active and attentive.
- Negative reviews need calm public replies and private follow-up.

Recommendations:

- Add review reply templates.
- Reply weekly to new reviews.
- Prioritize 1-3 star reviews first.
- Use a private feedback path to resolve issues before public complaints.

### 4. Photos and Visual Proof - 15 points

What to audit:

- Number of visible Place photos returned.
- Whether selected photo exists for website generation.
- Whether photos appear likely business-owned or generic/UGC based on attribution heuristic.
- Whether there is enough visual proof for the industry:
  - Contractors: projects, before/after, vehicles, crews, tools, job sites.
  - Restaurants/cafes: food, menu, interior, exterior, atmosphere.
  - Medical/salon/fitness: team, facility, treatment areas, equipment.
  - Retail: storefront, products, shelves/displays.
- Whether the generated site has gallery/hero imagery.

What not to claim yet:

- Do not claim posting frequency or freshness unless we add reliable date data.

Owner-facing message:

- Photos help visitors confirm the business is real and understand quality, atmosphere, work style, or products before calling.
- If competitors show more complete visuals, they can feel more credible even before a conversation.

Recommendations:

- Add 10-20 strong owner-provided photos.
- Add monthly photo refresh process.
- Add before/after or portfolio photos where relevant.
- Use owned photos on the launched website instead of relying permanently on Google photo references.

### 5. Business Profile Completeness - 15 points

What to audit:

- Business status is operational.
- Phone number exists.
- Address or service-area context exists.
- Hours exist.
- Category/type exists.
- Maps URL exists.
- Website URL exists or is missing.
- Address/city can be parsed for local search positioning.
- Business name appears usable and not keyword-stuffed.

Recommendations:

- Fill missing phone/hours/category fields.
- Confirm address/service area is correct.
- Keep holiday hours updated.
- Make category/service labels match what customers search.

### 6. Local Competitor Position - 15 points

What to audit:

- Competitor count in same query/city.
- Target rank in cached result set when known.
- Competitor website presence rate.
- Competitor average rating.
- Competitor median/top review count.
- Target relative rating.
- Target relative review count.
- Whether top competitors have websites while target does not.
- Whether the target has fewer photos than the visible competitor median when comparable.

Owner-facing message:

- The audit is not saying customers never call. It is showing where competitors look easier to trust before the first call.

Recommendations:

- Build missing website path.
- Add review generation system.
- Add profile photo plan.
- Add service pages aligned to the competitor query.

### 7. Conversion Readiness - 10 points

What to audit:

- Phone click path exists.
- Website/contact path exists.
- Feedback/review page exists in generated site.
- Services/offers can be explained before a call.
- Hours and location are visible.
- Final CTA exists in generated site.

Recommendations:

- Launch website preview.
- Add quote/contact form.
- Add "what to prepare before calling" FAQ.
- Add service pages and final CTA.
- Add sticky mobile call CTA.

### Persistence

Current implementation computes the audit on demand from data WebView.click already stores:

- Generated site JSON in D1/R2.
- `places_prospects.result_json` and `places_prospects.details_json`.
- `leads` fallback fields.
- Cached competitor rows in `places_search_cache`.

This means the audit endpoint does not need to call Google again just to rebuild the report. However, saving an audit JSON snapshot is still useful because it preserves the exact outreach version that an owner saw.

Recommended persistence path:

- Keep PDF generation client-side and on demand; do not store audit PDFs by default.
- Add R2 audit JSON snapshots under `audits/{businessId}/{auditId}.json`.
- Add a small D1 metadata table so admin can list snapshots without scanning R2:
  - `id`
  - `business_id`
  - `place_id`
  - `r2_json_key`
  - `score`
  - `confidence`
  - `query`
  - `source_hash`
  - `created_at`
  - `created_by`
- Save a snapshot when admin clicks `Save audit snapshot`. Keep copy/download actions non-writing unless a later workflow needs automatic history.
- Let `/audit/:businessId` default to latest live on-demand audit unless `?snapshot={auditId}` is present.
- Add a stale indicator if current live audit source hash differs from the saved snapshot hash.

Why save JSON if source data already exists:

- It preserves point-in-time score/copy/evidence for outreach consistency.
- It avoids drift when cached competitor rows are trimmed/refreshed.
- It lets admin compare before/after GBP optimization later.
- It keeps storage small compared with saving PDFs.

Why not save PDF:

- PDF can be regenerated from the saved audit JSON when needed.
- PDF storage is larger and less useful for programmatic comparison.
- Client-side PDF generation already works without a server job.

## Deterministic Owner Problem Copy System

The audit should feel custom even without AI. Do this with a deterministic copy registry that maps business category/niche to owner pressures, customer decision criteria, and specific audit wording.

Implementation target:

- Add `src/lib/marketingAuditCopy.ts`.
- Detect `industryGroup` from Google Places `types`, prospect query, generated site niche, offers/services, and business name keywords.
- Select the strongest matching industry profile, with a generic local service fallback.
- Fill copy slots with real audit evidence: website destination type, review rating/count gap, photo count, hours/phone presence, competitor website rate, and generated preview availability.
- Never output a problem sentence unless the triggering evidence exists.

### Copy Slot Model

Each industry profile should provide deterministic templates for these slots:

- `ownerPressure`: what the owner feels when demand is inconsistent.
- `customerDecisionMoment`: what the customer is trying to decide before calling.
- `websiteGapProblem`: why no website/social-only link hurts this specific industry.
- `reviewGapProblem`: how review count/rating affects the first-call choice in this industry.
- `photoGapProblem`: what photos prove in this industry.
- `competitorPressure`: why competitor proof matters locally.
- `operationalCostPressure`: what overhead or idle capacity means for this owner.
- `seasonalityPressure`: seasonal or weekly demand risk when relevant.
- `recommendationTone`: direct next-step wording tied to WebView.click services.

Example output assembly:

```ts
type AuditCopyProfile = {
  industryGroup: string;
  matchTypes: string[];
  matchKeywords: string[];
  ownerPressure: string[];
  customerDecisionMoment: string[];
  websiteGapProblem: string[];
  reviewGapProblem: string[];
  photoGapProblem: string[];
  operationalCostPressure: string[];
  seasonalityPressure?: string[];
  recommendationTone: string[];
};
```

The audit renderer should not show all copy. Pick 1-2 strongest problem frames based on scoring flags so the report stays direct.

### Deterministic Trigger Rules

- `website.kind === "missing"`: use no-website copy.
- `website.kind` is social/link hub/directory/booking-only: use partial-website copy.
- `reviewCount < competitorMedianReviewCount`: use review-volume copy.
- `rating < competitorAverageRating - 0.2`: use rating-gap copy.
- `photoCount < competitorMedianPhotoCount`: use visual-proof copy.
- `competitorWebsiteRate >= 0.6 && !website.countsAsFullWebsite`: use competitor website pressure copy.
- `hoursAvailable === false`: use operational trust/completeness copy.
- `phone missing`: use urgent contact-path copy.
- `generatedPreview exists`: recommend launching the preview as the fastest fix.

### Industry Problem Profiles

#### Dental / Medical / Clinics

Owner pressures:

- Chair time, rooms, assistants, hygienists, front desk, and equipment cost money whether the schedule is full or not.
- Empty appointment slots are expensive because staff and fixed costs still exist.
- Patients often compare trust, reviews, photos, accepted services, and whether the clinic feels professional before calling.

Website gap copy:

- Patients need to understand services, insurance/payment cues, clinic environment, hours, and how to book before they call.
- A social page is not enough for patients comparing treatment options or deciding whether the clinic feels credible.

Photo proof:

- Photos should reduce anxiety: front desk, treatment rooms, team, equipment, exterior, and parking/context.

Review pressure:

- Review count and rating are trust shortcuts for health-related decisions.

#### Home Services / Contractors

Owner pressures:

- Leads can be seasonal, weather-dependent, and uneven by week.
- Crews, vehicles, tools, insurance, and admin time still cost money when the schedule has gaps.
- Owners need enough qualified calls, not just random calls.

Website gap copy:

- Customers want to see services, service area, project examples, license/insurance cues, process, and quote expectations before calling.
- A Facebook page or directory profile does not organize that information like a contractor website.

Photo proof:

- Before/after work, job sites, vehicles, tools, crews, and finished results help people believe the business can do the job.

Review pressure:

- When customers compare contractors, review count can make one company feel safer to call first.

#### Restaurants / Cafes / Food

Owner pressures:

- Rent, staff, food cost, waste, and slow days can shrink margins quickly.
- Demand changes by daypart, weekday/weekend, season, weather, and local events.
- Owners need both first-time visitors and repeat traffic.

Website gap copy:

- Visitors want menu, hours, location, atmosphere, photos, catering/private event info, and reservation/order options before deciding.
- Social media helps with discovery, but it is a feed; it does not always answer basic visit questions quickly.

Photo proof:

- Food, menu, interior, exterior, atmosphere, and crowd/context photos drive confidence before a visit.

Review pressure:

- Diners often use rating and review count as a quick filter when choosing where to eat.

#### Salon / Spa / Beauty

Owner pressures:

- Empty appointment slots mean chairs, rooms, staff time, and product inventory are not earning.
- Trust matters because customers are choosing someone to work on appearance, comfort, or personal care.

Website gap copy:

- Customers want services, pricing cues, portfolio/results, staff specialties, booking flow, and policies before booking.
- Social profiles show posts, but they do not always make services, packages, and booking expectations clear.

Photo proof:

- Portfolio photos, treatment spaces, staff, cleanliness, and before/after results reduce hesitation.

Review pressure:

- Reviews matter because customers want proof that results are consistent.

#### Fitness / Wellness

Owner pressures:

- Rent, coaches, equipment, and class capacity create fixed costs even when attendance dips.
- Seasonality can be strong around New Year, summer, school schedules, and local routines.

Website gap copy:

- Prospects want programs, class schedule, trainer credibility, pricing cues, trial options, location, and what beginners should expect.

Photo proof:

- Facility, equipment, classes, trainers, and member experience help people imagine joining.

Review pressure:

- Reviews help prospects believe they will feel supported, not judged or confused.

#### Automotive

Owner pressures:

- Bays, technicians, lifts, equipment, parts workflow, and rent cost money whether every slot is full or not.
- Customers often call under stress and compare trust quickly.

Website gap copy:

- Customers need services, makes/models, warranty cues, hours, location, emergency/towing info, and booking/contact path.

Photo proof:

- Shop, bays, technicians, equipment, completed work, and storefront photos reduce doubt.

Review pressure:

- Review trust is critical because customers worry about price, honesty, and quality.

#### Legal / Professional Services

Owner pressures:

- Expertise is valuable, but leads only convert if prospects understand the service area and feel enough trust to start a conversation.
- Low-quality inquiries waste time; unclear positioning creates mismatched calls.

Website gap copy:

- Prospects need practice areas/services, process, credentials, location, consultation path, and plain-language answers before contacting.

Photo proof:

- Team, office, credentials, and professional environment create legitimacy.

Review pressure:

- Reviews and profile completeness help prospects decide who feels credible enough to contact first.

#### Retail / Local Shops

Owner pressures:

- Inventory, rent, staff, and slow foot traffic can squeeze cash flow.
- Customers may compare nearby options before visiting.

Website gap copy:

- Shoppers want product categories, brands, hours, location, photos, policies, and whether the shop has what they need before going.

Photo proof:

- Storefront, shelves, products, displays, and staff photos help customers decide the trip is worth it.

Review pressure:

- Reviews help people decide whether the store is worth visiting compared with other nearby options.

#### Generic Local Service Fallback

Owner pressures:

- Fixed costs continue even when inquiries slow down.
- The owner needs enough qualified customers to keep the calendar, team, and cash flow healthy.

Website gap copy:

- Customers need to understand services, proof, location, process, and how to contact the business before calling.

Photo proof:

- Real photos make the business feel active and credible.

Review pressure:

- Competitor reviews can influence who gets called first.

### Deterministic Copy Assembly

Build copy in this order:

1. Identify `industryGroup`.
2. Select strongest issue by score status:
   - urgent website gap
   - urgent review gap
   - urgent competitor gap
   - urgent photo gap
   - profile completeness gap
3. Select the relevant industry template.
4. Inject evidence:
   - business name
   - city/category
   - target rating/review count
   - competitor median/top review count
   - website kind label
   - competitor website rate
   - generated preview URL availability
5. Render one short owner-facing problem block:
   - "Why this matters"
   - "What customers may be comparing"
   - "What to fix first"
6. Render one direct offer block:
   - website launch/setup
   - GBP optimization
   - review generation system

Example deterministic sentence patterns:

- No website, contractor:
  - "When someone is comparing contractors in {city}, they usually want to see project examples, service area, quote expectations, and proof before they call. Right now the profile can send them to the phone, but it does not give them a full place to check those details first."
- Social-only URL, salon:
  - "The profile has a social link, but a feed is not the same as a service page. A new client still has to hunt for services, pricing cues, booking expectations, and proof of results."
- Review gap, dental:
  - "{businessName} has {reviewCount} reviews. The visible competitor median is {competitorMedianReviewCount}. For patients choosing a clinic, that gap can make another office look safer before they ever call."
- Slow-demand/overhead frame, restaurant:
  - "Slow days are expensive when rent, staff, and food cost keep moving. The profile and website need to answer visit questions quickly so more people choose to come in, order, or book instead of continuing to compare."

Copy safety:

- Say "may", "can", "often", and "before they call" unless using exact measured data.
- Do not say the business is losing customers.
- Do not diagnose finances; frame overhead as a common business pressure for that industry.
- Do not mention an industry pain unless the matched industry profile is confident.

## Copy Guidelines For The Audit

Use practical, owner-friendly language:

- "Customers can call you, but they cannot learn more before calling" for no-website profiles.
- "Competitors with more reviews can look safer to call first" for review gaps.
- "Photos reduce doubt before the first call" for photo gaps.
- Speak to the owner's pressure first, then present the service as the fix. The point is not "buy a website"; the point is fewer unanswered customer questions, stronger trust before the call, and a clearer path to qualified inquiries.
- Use category-specific wording from `marketingAuditCopy.ts` so a dentist, contractor, salon, cafe, auto shop, and professional service do not receive the same generic paragraph.
- "This is not a guarantee of ranking or calls; it is a profile-readiness comparison from available data."

Avoid:

- "You are losing X customers" unless we have real performance metrics.
- "You never respond to reviews" unless owner reply data exists.
- "You do not post regularly" unless photo/post recency data exists.
- Unverified competitor superiority claims beyond the exact compared fields.
